# Data

Raw data is not included because of its size and Kaggle's competition rules.

Download these 3 files from the M5 Forecasting – Accuracy competition on Kaggle and place them in this folder:
- calendar.csv
- sell_prices.csv
- sales_train_evaluation.csv

Model outputs in this folder:
- dept_elasticity.csv: price elasticity per department
- discount_profit_by_dept.csv: profit impact of discounts per department
